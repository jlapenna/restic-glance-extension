# Restic Glance Extension agent guide

## Fork source and harness maintenance

Read the [restic-glance-dev skill](.agents/skills/restic-glance-dev/SKILL.md) for source ownership,
checks, outcome evidence and fork delivery. Keep general maintenance procedures
with its shared owner and preserve this repository's operational boundaries.

Use the configured default branch (`master` in this fork), an isolated feature
worktree and reviewed PR delivery. Keep private backup data out of source and
shared evidence. A source-maintenance request does not authorize operations
on a backup repository or live deployment.
